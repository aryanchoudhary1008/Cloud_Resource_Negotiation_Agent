## Cloud Resource Negotiation Agent
2-Month Development Roadmap
This document summarizes the planned enhancements for the B.Tech project. It focuses on the implementation roadmap only and intentionally excludes code.
### Objective
Enhance the existing Cloud Resource Negotiation Agent into a technically strong, research-oriented B.Tech project with modern Reinforcement Learning, realistic cloud-provider simulation, improved documentation, experimentation, and presentation readiness.
### Phase 1: Foundation
1. Deep Q-Network (DQN) Integration
Replace the existing tabular Q-Learning implementation with a Deep Q-Network (DQN).
Introduce neural-network-based decision making for better generalization.
Support experience replay and target network mechanisms.
Keep both Q-Learning and DQN available for comparison.
Generate performance comparison between both approaches.
2. Multi-Provider Cloud Support
Add AWS, Google Cloud Platform (GCP), and Microsoft Azure provider simulations.
Assign different pricing strategies and negotiation behaviors to each provider.
Allow provider selection from the web interface.
Store provider information in negotiation history.
Compare negotiation success across providers.
3. Documentation Improvements
Prepare a professional README.
Document architecture, workflow, algorithms, setup process, and results.
Include project structure and future scope.
### Phase 2: Advanced Extension
Implement Curriculum Learning for progressive agent training.
Train the agent through Easy, Medium, Hard, and Expert negotiation scenarios.
Measure convergence speed and success-rate improvements.
Perform experiments comparing curriculum learning with normal training.
Prepare analytical reports with graphs and observations..
### Phase 3: Polish & Presentation
Redesign dashboard with interactive visualizations.
Display learning curves, provider comparison, and negotiation statistics.
Develop automated test cases for core modules.
Prepare complete project report (8–10 pages).
Create presentation slides with architecture, methodology, experiments, and results.
Prepare a live demonstration script.
### Expected Deliverables
Deep Q-Network based negotiation agent
Support for AWS, GCP, and Azure simulations
Curriculum Learning training pipeline
Interactive analytics dashboard
Comprehensive documentation
Final project report
Presentation slides
Live demonstration
Well-tested and reproducible project
### Expected Outcomes
Improved negotiation success rate.
Better generalization to unseen negotiation scenarios.
Comparison between classical and deep reinforcement learning.
Industry-oriented cloud negotiation simulation.
Higher technical depth suitable for B.Tech evaluation.
