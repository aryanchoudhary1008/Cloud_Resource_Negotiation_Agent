How Q-Learning Works

1 Agent observes state: (CPU, RAM, budget, price, round)
2 Picks action via ε-greedy: explore or exploit
3 Receives reward: +10 success / -10 fail / -1 per round
4 Updates: Q(s,a) ← Q(s,a) + α[r + γ·maxQ(s') − Q(s,a)]
5 Epsilon decays over time → more exploitation
